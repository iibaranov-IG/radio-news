# radio-news / КПNEWS

Редакционная система подготовки радиовыпусков новостей.

## Цель

Цель проекта — рабочий продукт для редактора:

```text
лента новостей
→ сюжеты и источники
→ подтверждённые факты
→ редакционный выбор
→ черновик выпуска
→ ручное утверждение
```

Архитектура, SQLite, CI и внутренние модели — средства достижения этой цели, но не замена пользовательскому результату.

## Текущий статус

```text
Исполняемое независимое ядро: готово
Horizon runtime dependency: отсутствует
Редакторский Web UI: следующий приоритет
Первый видимый выпуск: ещё не готов
```

Первый независимый вертикальный срез уже реализован:

```text
Source
→ RawItem
→ NormalizedItem
→ Story
→ Claim
→ Manual Fact
→ VerificationResult
→ SQLite
```

Автоматическая публикация в эфир не предусмотрена: итоговый выпуск утверждает человек-редактор.
