# Chief News Editor — архитектурная спецификация

## Роль

Editorial Personas объясняют, почему сюжет важен с конкретной профессиональной точки зрения. Chief News Editor формирует целостную информационную картину выпуска. Rundown Engine проверяет техническую допустимость. Человек утверждает результат.

## Вход

```text
Все проверенные сюжеты
+ Persona Recommendations
+ общий редакционный score vector
+ история ротации
+ контекст выпуска
```

Рекомендации персон — экспертные сигналы, но не единственный источник кандидатов. Главный новостник обязан видеть сильные сюжеты, которые не рекомендовала ни одна персона.

## Результат

Результат Chief News Editor — не rundown, а версионируемый `EditorialSlate`.

```text
Story
→ Verification
→ Persona Recommendations
→ Chief Editor Decisions
→ Editorial Slate
→ Radio Scripts selected + reserve
→ Rundown Variants
→ Human Approval
```

## Типы консенсуса

- профильный — несколько близких редакционных оптик;
- междисциплинарный — разные оптики пришли к высокой оценке;
- уникальная экспертиза — высокий сигнал одной профильной персоны.

Простое среднее всех персон не используется.

## Защита уникальной ценности

Высокий `unique_value_score` не гарантирует эфир, но запрещает автоматическое отбрасывание без явного решения:

```text
SELECTED
RESERVE
DEFERRED_TO_PROGRAM
REJECTED_LOW_AUDIENCE_REACH
REJECTED_NO_NEW_FACT
REJECTED_TIME_CONSTRAINT
REJECTED_TOPIC_OVERLOAD
```

## Покрытие

Система показывает не квоту имён ведущих, а отсутствие редакционных перспектив:

- технологии;
- инфраструктура;
- человеческая история;
- региональный аспект;
- практические последствия;
- управление и ответственность.

Отсутствие перспективы может быть допустимым, если в потоке нет подтверждённого материала достаточной значимости.

## Этапы работы

1. Детерминированно сформировать допустимый пул.
2. Вычислить отдельные сигналы кандидатов.
3. Оценить набор целиком: coverage, diversity, redundancy, emotional sequence, topic concentration, development continuity.
4. Сформировать несколько Editorial Slate.
5. Передать selected и reserve в Radio Writer.

`NO_NEW_FACT` не всегда блокирует повтор. Для главной темы дня возможен статус `REPEAT_REQUIRES_EDITORIAL_JUSTIFICATION`.

## Структурированные причины

```python
class DecisionReason:
    code: str
    weight: float
    explanation: str
    evidence: list[str]
```

Каждый выбор и отказ должен иметь машиночитаемые коды и evidence, из которых строится человеческое объяснение.

## Граница с Rundown Engine

Chief Editor:

- определяет значимость;
- выбирает картину дня;
- назначает editorial roles;
- формирует selected/reserve/rejected.

Rundown Engine:

- проверяет длительность;
- применяет обязательные блоки;
- строит позиции;
- выбирает короткую или расширенную погоду;
- оптимизирует мягкие ограничения.

Chief Editor не управляет техническими квотами выпуска.
